# سجل القواعد والأدلة وتدقيق الأثر

يسجل `Mosab\QafyaDetector\Support\QafyaRuleRegistry` معرّفات القواعد التي يصدرها تحليل الكلمات والقصائد، مع وصف الغرض وطبقة التنفيذ وروابط اختبارات الانحدار والمراجع المتاحة.

## ما الذي يقدمه السجل؟

- حصر القواعد عبر `QafyaRuleRegistry::all()` والبحث عن قاعدة عبر `QafyaRuleRegistry::get($id)`.
- ربط كل قاعدة بقصد التنفيذ والاختبارات ذات الصلة.
- اكتشاف معرّفات الأثر غير المسجلة بواسطة `unknownTraceRules()`.

السجل أداة صيانة وتدقيق، وليس شهادة بصحة القاعدة علمياً. يثبت اختبار الانحدار ثبات السلوك، لكنه لا يثبت وحده صحة التفسير اللغوي. تحمل مداخل السجل حالة مراجعة علمية معلقة، وتحتاج المراجع الببليوغرافية إلى استكمال بيانات الطبعة والصفحة والمراجعة المباشرة.

## تدقيق أثر محفوظ

احفظ نتيجة كلمة بصيغة JSON ثم نفذ:

```bash
php tools/audit-rule-trace.php /path/to/word-result.json
```

يعيد الأمر حالة خروج غير صفرية إذا احتوى الأثر على معرّفات غير مسجلة. عند إضافة قاعدة جديدة، أضف مدخلاً في السجل واختبار انحدار، ووثّق شروط التطبيق والاستثناءات والتعارضات مع القواعد الأخرى، واستكمل بيانات المرجع العلمي قبل تغيير حالة المراجعة.

## الأدلة والبدائل المحتملة

يظهر الدليل المنظم وعدم اليقين في `diagnostics.evidence` و`diagnostics.uncertainty`، وتظهر القراءات المرشحة في `diagnostics.candidates`. تمثل النتيجة المختارة أحد المرشحين. وقد تعرض بعض حالات الهاء الملتبسة بديلاً بنيوياً دون اختلاق درجة ثقة له. وتظل `candidate_set_complete: false` عندما لا يسرد الكاشف جميع احتمالات تفسير الروي والوصل.

ينبغي عرض البدائل باعتبارها أدلة تستحق المراجعة، لا تنبؤات ثبت تساويها في الصحة. أبقِ معرّفات القواعد المجهولة وعدم اكتمال البدائل والتحذيرات وحدود القافية غير المكتملة ظاهرة في أدوات المراجعة الداخلية.
