# موسوعة القافية — Mosab Qafya Detector

توفر حزمة **Mosab Qafya Detector** مكتبة PHP لتحليل القافية العربية بصورة منظمة وقابلة للدمج في التطبيقات. تستخرج الروي ومكونات القافية، وتحلل نهايات أبيات القصيدة في سياقها، وتعرض عيوب القافية والسناد المحتمل، وتعيد كائنات PHP أو مصفوفات قابلة للتحويل إلى JSON.

صُممت واجهة الحزمة لتناسب التطبيقات الفعلية: فالنتيجة تتضمن الحالة، والأدلة، والتحذيرات، ومواضع الالتباس، وأثر القواعد، ومجموعات القافية ومؤشرات المراجعة؛ وبذلك يستطيع التطبيق التمييز بين نتيجة قابلة للاستخدام ونتيجة تحتاج إلى مراجعة تحريرية أو عروضية.

## الاستخدام الفعلي: تصنيف القصائد في موسوعة الشعراء

صُممت هذه الحزمة **لتصنيف القصائد العربية بحسب القافية والروي على مستوى القصيدة**، وليس لتحليل الكلمات المفردة فقط. وهذه الوظيفة تعمل بالفعل في الموقع الحي **[موسوعة الشعراء](https://poetspedia.com/)**؛ ويمكن مشاهدة النتائج من **[صفحة القوافي الشعرية](https://poetspedia.com/rhymes/)**.

هذا تنفيذ مستخدم فعلياً، وليس ميزة مستقبلية مقترحة. ومع ذلك، تصف الصفحة العامة التصنيف الآلي بأنه تجريبي؛ فالنهايات النادرة أو غير المشكولة أو الملتبسة قد تحتاج إلى مراجعة بشرية. تعرض الحزمة حالات التحليل والمجموعات والأدلة والتشخيصات كي لا يضطر التطبيق المستهلك إلى تقديم كل نتيجة بوصفها حكماً عروضياً قطعياً. اقرأ [تفاصيل الاستخدام الفعلي وحدوده](production-use.md).

## المتطلبات

- PHP **8.4 أو أحدث** (`^8.4`).
- تفعيل امتداد `mbstring` لمعالجة النص العربي والمواضع النصية متعددة البايتات.
- Composer.
- دعم Laravel اختياري، ويُكتشف مزود الخدمة تلقائياً داخل تطبيق Laravel.

## التثبيت

```bash
composer require helturkey/mosab-qafya-detector
```

## الاستخدام السريع: تحليل كلمة أو نهاية

```php
use Mosab\QafyaDetector\QafyaDetector;

$detector = QafyaDetector::make();
$result = $detector->extract('ناداها');

$result->status();          // ok
$result->rawi();            // ه
$result->radf();            // ا
$result->wasl();            // ا
$result->patternSurface();  // اها
$result->confidenceLevel();
$result->warnings();
```

## تحليل قصيدة

يمكن تمرير القصيدة في صورة قائمة من الأشطر أو نص يمكن لمقسّم الأسطر تحليله. افتراضياً يُحلل عجز كل بيت مكتمل، ويمكن تفعيل `analyze_sadr` لتحليل الصدر والعجز معاً.

```php
$analysis = $detector->analyze([
    'قفْ بالديار وصحْ إلى بيداها',
    'فعسى الديار تجيبُ منْ ناداها',
]);

$analysis->status();
$analysis->rawi();
$analysis->qafyaPattern();
$analysis->hasMultipleQafyas();
$analysis->dominantRatio();
$analysis->clusters();
$analysis->endings();
$analysis->defects();
$analysis->sanad();
```

## خيارات التحليل

تُمرر الخيارات كمصفوفة ترابطية أو كائن `Mosab\QafyaDetector\Support\QafyaOptions`:

```php
$analysis = $detector->analyze($poem, [
    'mode' => 'auto',                 // auto | heuristic | scholarly
    'strict_harakat' => true,
    'analyze_sadr' => false,
    'detect_defects' => true,
    'detect_sanad' => true,
    'use_linguistic_evidence' => false,
]);
```

يختار `auto` وضع تحليل حدود القافية وفق وجود علامات تشكيل ذات معنى على آخر كلمة عربية. واسم الوضع `scholarly` لا يعني أن النتيجة راجعها عالم أو أُقرت علمياً. التكامل مع مزود لغوي ومعايرة الثقة خياران صريحان وليسا اتصالاً خارجياً تلقائياً.

## التكامل مع Laravel

```php
use Mosab\QafyaDetector\Laravel\Facades\QafyaDetector;

$result = QafyaDetector::extract('كتابُهُ');
$analysis = QafyaDetector::analyze($poem);
```

لنشر ملف الإعداد الاختياري:

```bash
php artisan vendor:publish --tag=mosab-qafya-detector-config
```

## أداة سطر الأوامر

من جذر مستودع المصدر:

```bash
php bin/qafya word "البركة"
php bin/qafya word "البركة" "الديكة" --json
php bin/qafya poem poem.txt --json
```

بعد تثبيت الحزمة داخل تطبيق آخر:

```bash
php vendor/helturkey/mosab-qafya-detector/bin/qafya word "البركة" --json
```

يحتوي ملف القصيدة على شطر واحد في كل سطر، وتوضح المساعدة استخدام `***` للفصل بين شطري البيت. اعرض الخيارات المتاحة بواسطة `--help`.

## قراءة النتائج

- `ok`: تم إنتاج نتيجة للروي في المدخل المحلل.
- `review`: ظهرت قرائن تستدعي المراجعة، مثل تعدد مجموعات الروي أو عيوب مانعة.
- `partial`: المدخل أو الدليل الصوتي غير مكتمل للتحليل الكامل.
- `error`: تعذر إكمال التحليل.

على مستوى القصيدة، تُحدد هوية القافية العامة بواسطة **الروي المعياري**. وتبقى تفاصيل الردف والوصل والخروج والتأسيس والدخيل والحركات في تفاصيل كل نهاية، ويمكن أن تسهم في العيوب أو السناد. يعرض `dominant` القافية العامة عندما تتحقق سياسة الاعتماد، بينما يوفر `indexing` إحصاءات المجموعة الأكثر تكراراً للاستخدام في البحث والتصفية.

درجة الثقة الخام درجة أدلة مبنية على قواعد وليست احتمالاً معايراً إحصائياً. لا تستخدم نتائج النص غير المشكول أو الحالات الملتبسة بوصفها حكماً عروضياً نهائياً من دون مراجعة مختصة.
